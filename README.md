One original line of office comedy: a printer broken since March, a meeting to fix it rescheduled seven times, and the punchline that the printer has earned a promotion to middle management. `main.py` is a small deterministic Python program that writes the joke to `$MAKEFUN_OUTPUT_DIR/entry.txt`, checks it is a single line of at most 200 characters, and exits non-zero if the contract is ever violated.

## Run it

```sh
python3 main.py
```
